# Темы сообщества

Готовые темы для AI Hub в формате JSON. Чтобы поставить тему: **`[ВИД]` → «Импорт JSON»** и выбери файл.

Сделал свою тему — экспортируй её в редакторе («Экспорт JSON») и пришли pull request с файлом в эту папку.
Формат и список переменных — в основном [README](../README.md#свои-темы).
